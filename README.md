# lms-design-preview

Static design preview for Mereka LMS Academy v2 (OpenEdX Paragon-aligned).

This is a **build-artifact-only** repo. The canonical truth is `dist/`.
No source code, no build tooling.

To update:

1. Drop the new `dist/index.html` and any new asset files into `dist/`.
2. PR with a screenshot.
3. Merge → Coolify auto-deploys.

Deployed at:

- https://lms-prototype.deploy.mereka.io (canonical, Coolify Cloud)
